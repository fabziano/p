Bases de dados acadêmicas

A mesma string de busca pode ser aplicada em diferentes bases para que a comparação seja realizada de forma equivalente. Dessa forma, podemos observar como cada base responde à mesma necessidade de pesquisa.

Quantidade

A quantidade de resultados mostra o volume de trabalhos recuperados pela mesma busca em cada base. Esse número será registrado para permitir uma comparação direta entre os resultados.

Relevância

Além da quantidade, é necessário observar a relação dos resultados com o tema pesquisado. A análise considera se os trabalhos recuperados realmente respondem à estratégia de busca utilizada.

Duplicidade

Um mesmo trabalho pode aparecer em diferentes bases. A comparação permite identificar essas duplicidades e observar quanto dos resultados recuperados é compartilhado entre as bases.

Filtros

Os filtros permitem restringir os resultados encontrados. Devemos comparar recursos como período, idioma, tipo de publicação, autor, assunto e disponibilidade do texto completo.

Metadados

Os metadados descrevem cada publicação e podem incluir título, autores, ano, periódico, DOI, resumo e palavras-chave. A comparação mostra quais informações cada base disponibiliza.

Exportação

A exportação permite utilizar os resultados em outras ferramentas. Devemos observar quais formatos estão disponíveis e quais informações são preservadas no arquivo exportado.
